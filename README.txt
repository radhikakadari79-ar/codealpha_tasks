TASK 4: BASIC CHATBOT

Project Name:
Basic Chatbot using Python

Description:
This project is a simple rule-based chatbot developed using Python.
The chatbot interacts with the user and provides predefined responses
to simple messages.

Features:
- Accepts user input.
- Responds to greetings.
- Responds to "How are you?"
- Responds to "Bye".
- Provides predefined replies.
- Continues the conversation using a loop.

Technologies Used:
- Python

Python Concepts Used:
- If-elif-else statements
- Functions
- While loop
- User Input
- Strings

How to Run:
1. Open the Python file in VS Code.
2. Run basic_chatbot.py.
3. Enter a message in the terminal.
4. The chatbot will provide a predefined response.
5. Type "bye" to end the conversation.

Result:
The Basic Chatbot was successfully executed and tested.
