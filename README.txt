TASK 2: STOCK PORTFOLIO TRACKER

Project Name:
Stock Portfolio Tracker using Python

Description:
This project is a simple Stock Portfolio Tracker developed using Python.
The user enters stock names and quantities, and the program calculates
the total investment value based on predefined stock prices.

Features:
- Uses a predefined stock price dictionary.
- Accepts stock names from the user.
- Accepts the quantity of each stock.
- Calculates the total investment value.
- Displays the portfolio details.
- Saves the result to a text file.

Technologies Used:
- Python

Python Concepts Used:
- Dictionaries
- User Input
- Arithmetic Operations
- Loops
- File Handling

How to Run:
1. Open the Python file in VS Code.
2. Run stock_portfolio_tracker.py.
3. Enter the number of stocks.
4. Enter the stock name and quantity.
5. The program calculates the total investment value.
6. Choose whether to save the result to a text file.

Result:
The Stock Portfolio Tracker was successfully executed and tested.
The total investment value was calculated successfully.
