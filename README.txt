TASK 1: HANGMAN GAME

Project Name:
Hangman Game using Python

Description:
This project is a simple Hangman game developed using Python.
The player has to guess a hidden word by entering letters.
The game provides a limited number of incorrect guesses.

Features:
- Uses predefined words.
- Accepts user input.
- Shows the guessed letters.
- Allows a maximum of 6 incorrect guesses.
- Displays the result when the player wins or loses.

Technologies Used:
- Python

Python Concepts Used:
- Lists
- Strings
- Random module
- While loop
- If-else statements
- User input

How to Run:
1. Open the Python file in VS Code.
2. Run hangman_game.py.
3. Enter letters to guess the hidden word.
4. Continue until the word is guessed or the maximum incorrect guesses are reached.

Result:
The Hangman game was successfully executed and tested.
